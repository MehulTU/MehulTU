## Featured project

**[Assembly Monitor](https://github.com/MehulTU/Assembly-Monitoring-System-V2)**: a modular computer-vision framework that monitors manual assembly. Version 1 uses classical OpenCV motion analysis; Version 2 adds a custom-trained YOLO11 detector, temporal filtering, assembly-state estimation, event logging and a quantitative validation pipeline against ground truth.

```
Acquisition → Calibration → YOLO11 detection → Temporal filtering
            → State estimation → Decision engine → Analytics → Validation
```
